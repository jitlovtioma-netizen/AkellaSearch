# Akella Search: медиа из Google Drive для Foundry VTT

Модуль для Foundry VTT **V13 и V14**, работает с любой игровой системой. Он похож на Moulinette Media Search, только файлы берутся из вашей папки Google Drive.

- **Поиск** по картам, тайлам, звукам, видео и сценам во всех подпапках диска.
- **Перетаскивание на сцену**: картинка или видео становится тайлом, аудио становится звуком окружения, файл сцены импортируется целиком.
- **Сцена из карты** в один клик. Размер сетки угадывается из имени файла, например `Таверна 30x20.webp`.
- **Сцен-паки**: сцена со стенами, дверьми, светом, звуками, тайлами, заметками, регионами и токенами. Все нужные файлы сами скачиваются с диска.
- **Universal VTT** (`.dd2vtt`, `.uvtt`, `.df2vtt` из Dungeondraft, DungeonFog и др.): стены, двери и свет создаются автоматически.
- **Плейлисты**: добавить трек с диска в плейлист.
- **Загрузка на диск с автосортировкой**: перетащите файлы в окно модуля, и они лягут в `Maps/<автор>/<карта>`, `Tokens/<автор>`, `Music/<автор>` и т.д. Сцену можно выгрузить сцен-паком через меню сцены «Выгрузить на Google Drive».
- **Конвертация**: при загрузке png/jpg превращаются в webp, а mp3/wav/flac в ogg (Opus), прямо в браузере. Уже лежащие на диске файлы можно сконвертировать кнопкой в окне модуля.
- **Перенос модулей с картами**: кнопка «Перенос» выгружает на диск все сцены установленного модуля (или текущего мира) сцен-паками со стенами, светом, звуками и файлами.
- **Конвертер V13 → V14**: многоэтажные карты из модулей Levels и Wall Height превращаются в родные уровни V14.

## Установка

В Foundry откройте **Add-on Modules → Install Module** и вставьте ссылку на manifest:

```
https://raw.githubusercontent.com/jitlovtioma-netizen/AkellaSearch/main/module.json
```

Можно поставить и вручную: распакуйте `akella-search.zip` в `Data/modules/akella-search/`.

## Настройка Google Drive

### 1. Папка

Откройте папку на диске: **Поделиться → Все, у кого есть ссылка → Читатель**. Ссылку на папку (или её ID) укажите в настройках модуля. По умолчанию там уже стоит ваша папка.

### 2. API-ключ (для просмотра и скачивания)

1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/) и создайте проект.
2. Откройте **APIs & Services → Library**, найдите **Google Drive API** и нажмите **Enable**.
3. Откройте **APIs & Services → Credentials → Create credentials → API key**.
4. Рекомендуется ограничить ключ: **API restrictions → Google Drive API**, а в **Application restrictions → Websites** указать адрес вашего Foundry.
5. Вставьте ключ в настройку модуля **«API-ключ Google»**.

Ключ виден всем подключённым к миру клиентам, поэтому обязательно ограничьте его только Drive API.

### 3. OAuth-клиент (только для загрузки на диск)

Без этого шага всё работает, кроме загрузки файлов и выгрузки сцен на диск.

1. Откройте **APIs & Services → OAuth consent screen**: тип **External**, заполните название и email.
2. Нажмите **Publish app** (статус **In production**). В режиме Testing Google сбрасывает вход каждые 7 дней. Проверка Google для личного использования не нужна: при входе просто нажмите «Дополнительно → Перейти».
3. Откройте **Credentials → Create credentials → OAuth client ID**, тип **Web application**.
4. В **Authorized redirect URIs** добавьте `http://localhost:30000/modules/akella-search/oauth.html` (замените начало на свой адрес Foundry; точный адрес показан в окне входа). Google принимает только `https://…` или `http://localhost`.
5. Скопируйте **Client ID** и **Client secret** в настройки модуля.
6. В окне модуля нажмите **«Войти в Google»** → **«Открыть страницу входа Google»**. В приложении Foundry страница откроется в обычном браузере: войдите, скопируйте код со страницы «Akella Search» и вставьте его в окно Foundry. Это делается один раз: дальше модуль сам продлевает доступ, и загрузка не обрывается через час.

### Большие загрузки

- Файлы уходят на диск по 6 одновременно (настройка «Одновременных загрузок», до 10).
- Галочка «Пропускать файлы, которые уже есть на диске» включена по умолчанию: если загрузка прервалась, запустите её снова, уже загруженное пропустится без повторной конвертации.
- В окно модуля можно перетащить целую папку, вложенные папки сохранятся.
- Все варианты одной карты кладутся в одну папку по её базовому имени: `Zen Monastery - 03a Autumn Day`, `Zen Monastery - 15b Winter Night` → `Zen Monastery`; `Zen Garden Monastery (Winter Night)`, `Zen Garden Monastery Animated - 01a 4k` → `Zen Garden Monastery`; `01LiarBar`, `Liar Bar - 02 Night` → `LiarBar`. Номера, коды 01a/2F, дни/ночи, сезоны, Animated, 4k/FHD в имя папки не попадают, а имена файлов не меняются. Уже разбитые папки объединяет кнопка с иконкой групп в окне модуля.
- Карты, у которых есть JSON сцены (стены, свет, звуки), выделены оранжевой рамкой с подписью «Готовая сцена», а JSON показывает превью своей карты. В фильтре типов есть «Готовые сцены».

## Как пользоваться

- Окно открывается кнопкой Google Drive на панели тайлов, кнопкой во вкладке «Сцены» или сочетанием **Ctrl+Shift+M**.
- При первом запуске нажмите **«Обновить индекс»**: модуль просканирует диск. Индекс сохраняется на сервере Foundry, его нужно обновлять, когда на диске появляются новые файлы. Файлы, загруженные через модуль, попадают в индекс сразу.
- Файлы с диска при первом использовании копируются в хранилище Foundry (папка `gdrive-media/`, её можно поменять в настройках). Поэтому игроки загружают их с вашего сервера, а не с Google.

### Структура диска

```
Maps/<Автор>/<Карта>/   карта, её JSON сцены и все файлы сцены
Tokens/<Автор>/          Tiles/<Автор>/
Music/<Автор>/           Ambience/<Автор>/     SFX/<Автор>/
Other/
```

Автор берётся из поля в окне загрузки, по умолчанию последний введённый. Если имя файла вида `Tom Cartos - Tavern.jpg` или `[Tom Cartos] Tavern.jpg`, автор подставится сам. Раздел определяется по типу файла, подсказкам в имени (token, tile, ambience, sfx…) и размеру картинки, его можно выбрать и вручную. Автосортировку можно выключить в настройках, тогда файлы попадут в выбранную в окне папку.

### Формат сцен-пака на диске

```
Maps/Tom Cartos/
  Таверна/
    Таверна.json      ← экспорт сцены Foundry (стены, свет, звуки, тайлы…)
    Таверна.webp      ← фон
    fire.ogg, door.png …
```

- JSON может быть обычным экспортом сцены из Foundry (**ПКМ по сцене → Export Data**) или выгрузкой этого модуля.
- Пути к файлам внутри JSON сопоставляются по имени файла: сначала ищется в папке пака, потом по всему диску. Если файл сконвертирован (`map.png` → `map.webp`), он всё равно найдётся. Файлы, которые уже есть на сервере (например, иконки ядра), не трогаются.
- Если загружать JSON вместе с картой и файлами одной пачкой, всё ляжет в одну папку, а ссылки в JSON поправятся под новые имена после конвертации.
- Если рядом с картой лежит JSON с тем же именем, на карточке появляется значок сцен-пака, а кнопка «Создать сцену» импортирует сцену целиком.

### V13 и V14

| Источник → куда | Что происходит |
|---|---|
| Сцена V13 → мир V13 | Обычный импорт. |
| Сцена V13 → мир V14 | Ядро V14 само переносит фон в первый уровень. Если в сцене есть этажи модуля Levels, в диалоге импорта можно сразу конвертировать их в уровни V14. |
| Сцена V14 с уровнями → мир V13 | В V13 уровней нет: можно выбрать один уровень или импортировать каждый уровень отдельной сценой. |
| Сцена V14 → мир V14 | Обычный импорт, уровни сохраняются. |

### Конвертер в уровни V14

ПКМ по сцене в V14 → **«Конвертировать в уровни V14»**. По умолчанию модуль работает с копией, оригинал не меняется.

Что переносится:

| Было (V13, Levels + Wall Height) | Стало (V14) |
|---|---|
| Этажи сцены `levels.sceneLevels` (или высоты тайлов) | Уровни (Level) с диапазоном высот |
| Полноразмерный тайл пола этажа | Фон уровня |
| Высота стен (Wall Height) | Привязка стены к уровням |
| Высота тайлов | Привязка тайла к уровню |
| Диапазоны света, звуков, заметок | Привязка к уровням и высота |
| Высота токенов | Уровень токена |
| Рисунки-лестницы и лифты | Регионы «Смена уровня» (Change Level) |
| Рисунки-дыры | Дыры в поверхности пола верхнего этажа |
| — | Регион «Поверхность» (Define Surface) для каждого верхнего этажа |

После конвертации проверьте сцену. Нестандартные настройки (например, отдельные «крыши» Better Roofs) может понадобиться поправить вручную.

## API для макросов

```js
const api = game.modules.get("akella-search").api;
api.open();                                     // окно поиска
api.search({ query: "таверна", kind: "image" }); // поиск по индексу
await api.rebuildIndex();                       // пересканировать диск
await api.convertLegacyLevels(canvas.scene);    // конвертер V14
await api.exportSceneToDrive(canvas.scene);     // выгрузить сцену на диск
```

## Выпуск новой версии

1. Поменяйте `version` в `module.json` (например, `1.2.1`).
2. Запустите `./build.sh`, он пересоберёт `dist/akella-search.zip`.
3. Закоммитьте и запушьте в `main`. Foundry увидит обновление по ссылке на manifest.

Можно публиковать и через релизы GitHub с тегом вида `v1.0.1`: GitHub Actions сам соберёт архив и прикрепит его к релизу.
