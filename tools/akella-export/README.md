# Akella Export

Скрипт для ПК: находит в Foundry модули с картами, вынимает из их компендиумов сцены (стены, двери, свет, звуки), конвертирует картинки в webp и звук в ogg, пропускает 4K-видео и раскладывает всё в папку Google Drive по схеме Akella Search:

```
Maps/<Автор>/<Карта>/   сцена .json + карта + её файлы
Tokens/<Автор>/<Модуль>/   Tiles/…   Music/…   Ambience/…   SFX/…
```

Загружает уже программа Google Drive для компьютера, поэтому скорость как у неё.

## Что нужно

1. [Node.js LTS](https://nodejs.org) (версия 18 или новее).
2. Программа [Google Drive для компьютера](https://www.google.com/drive/download/), вход в тот же аккаунт.
3. Папка библиотеки (та, что указана в настройках Akella Search) должна быть видна в проводнике, например `G:\Мой диск\Akella`. Если папка вам расшарена, а не ваша: в веб-версии диска **ПКМ → Упорядочить → Добавить ярлык на Мой диск**.

## Запуск

1. Распакуйте архив в любую папку, например `C:\akella-export`.
2. Закройте Foundry (не обязательно, но так надёжнее).
3. Запустите `1-scan.bat`. В первый раз он сам поставит зависимости (около минуты). Если Foundry стоит не в стандартном месте, запустите из командной строки:
   `1-scan.bat --data "D:\Foundry\Data" --out "G:\Мой диск\Akella"`
4. Скрипт покажет найденные модули и создаст `akella-export.config.json`. Откройте его в Блокноте:
   - `"out"`: путь к папке библиотеки на Google Drive;
   - у каждого модуля `"include": true/false` (переносить или нет) и `"author"` (имя папки автора);
   - `"loose": false`, если отдельные файлы модуля без сцен не нужны.
5. Запустите `2-run.bat`. Можно прервать (Ctrl+C или закрыть окно) и запустить снова: готовое пропустится.
6. Когда Google Drive догрузит файлы, в Foundry в окне Akella Search нажмите **«Обновить индекс»**.

## Полезные параметры

| Параметр | Что делает |
|---|---|
| `--modules id1,id2` | перенести только эти модули |
| `--jobs 6` | сколько файлов конвертировать одновременно (по умолчанию половина ядер) |
| `--dry-run` | только показать, что будет сделано |
| `--no-convert` | копировать без конвертации |

В `akella-export.config.json` также настраиваются качество webp (`webpQuality`, 85), битрейт ogg (`audioBitrate`, 128), максимальная высота видео (`maxVideoHeight`, 1080) и какие разделы брать из отдельных файлов (`looseCategories`).

## Как он решает, что делать

- **Модули с картами**: в имени есть master, snowystar, map, battlemap, czepeku и т.п., или в компендиумах есть сцены с картой из папки модуля.
- **Сцены** читаются из компендиумов LevelDB (Foundry 11–14) и старых `.db`, включая сцены внутри приключений (Adventure).
- **4K**: отдельные 4K-видео пропускаются. Если сцена ссылается на 4K, берётся Full HD версия рядом; если её нет, скрипт сам уменьшит видео до 1080p.
- **Папки** называются по карте без номеров и вариантов: `Zen Monastery - 03a Autumn Day` → `Zen Monastery`.
- Общие файлы (звуки дверей, ассеты) копируются один раз.
- Прогресс хранится в `akella-export.state.json`, журнал в `akella-export.log`.

Google Drive в режиме «Потоковая передача» держит файлы на локальном диске, пока не загрузит их, поэтому нужно свободное место примерно с объём результата (обычно в 2–3 раза меньше исходника).
